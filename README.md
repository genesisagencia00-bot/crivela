# Crivela — rede social de campanhas publicitárias

Protótipo front-end responsivo em HTML, CSS e JavaScript puro.

## Como abrir

1. Extraia a pasta.
2. Abra `index.html` no navegador.
3. Para uma experiência melhor, sirva a pasta com um servidor local, por exemplo:
   - VS Code + extensão Live Server; ou
   - `python3 -m http.server 8000`

## Recursos incluídos

- Feed de campanhas com cards visuais autorais em CSS.
- Filtros por categoria e busca instantânea.
- Modos lista e grade.
- Curtir, salvar, seguir e compartilhar.
- Modal funcional para publicar nova campanha.
- Layout responsivo com navegação mobile.
- Logo original em `assets/logo-crivela.png`.

## Personalização rápida

As cores principais ficam no início de `styles.css`, dentro de `:root`.
Os conteúdos de exemplo ficam nos arrays do arquivo `script.js`.
